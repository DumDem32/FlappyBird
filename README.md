# Flappy Clone

A from-scratch, browser-based Flappy Bird-style game.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js`.
3. In **Settings → Pages**, choose the main branch and root folder.
4. Save and open the generated Pages URL.

## Controls
- Space / Up Arrow
- Mouse click
- Touch

This project uses original code and replacement artwork rather than the original game's copyrighted source code or assets.
